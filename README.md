# Pip-Boy 3000 — Ultimate Edition

> *Fan-made Pip-Boy 3000 replica — interactive personal computer in Fallout style.*

Interactive web app with Pip-Boy CRT terminal aesthetics. Features map, habit tracker with RPG stats, notes, mini-games and more.

---

## Features

| Feature | Description |
|---------|-------------|
| 🗺️ **Map** | Leaflet map with markers, routes, distance measurement |
| 📊 **S.P.E.C.I.A.L. Stats** | RPG stats derived from habit completions |
| ✅ **Habits** | Daily habit tracker with streaks and XP |
| 📝 **Notes** | Categorized notes (Quest, Journal, Location, Character) |
| 🎮 **Mini Games** | Galaga-style space shooter in CRT green |
| 🚌 **Transport** | Bus/Tram/Metro schedules |
| 📱 **PWA** | Installable, offline-capable |
| 🌍 **Bilingual** | Russian / English interface |

## Mini Games

### Galaga
Classic space shooter in Pip-Boy CRT style. Destroy waves of enemies, beat your high score!

- **Controls:** Arrow keys + Space (keyboard) or touch buttons (mobile)
- **Scoring:** 30 / 20 / 10 points by enemy row
- **High scores** saved in browser

## Tech Stack

- **Framework:** Next.js 16 (static export)
- **State:** Zustand (localStorage persistence)
- **Maps:** Leaflet + OpenStreetMap
- **Styling:** Custom CRT terminal theme (CSS)
- **Hosting:** GitHub Pages
- **PWA:** Manifest + Service Worker
