# Pip-Boy Ultimate

Fallout-inspired personal assistant PWA with interactive map, habit tracker, notes, and RPG stats system.

## Features
- Interactive map with markers, routes, and distance measurement
- City search (Nominatim)
- Map position memory (persists zoom and center)
- Fly-to-marker navigation
- Habit tracker with S.P.E.C.I.A.L. RPG stats
- Notes system with categories and pinning
- Transport schedules for European cities
- PWA with offline support
- Pip-Boy 3000 CRT screen aesthetic
- EN/RU localization
